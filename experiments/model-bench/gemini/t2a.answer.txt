**CLEAN**

- **Pool-wide enforcement:** All requirements (WAL mode, `busy_timeout=5000`, and `foreign_keys=ON`) are already applied to **every** connection in the pool via the DSN parameters (`_journal_mode=WAL`, `_busy_timeout=5000`, and `_pragma=foreign_keys(1)`), which `modernc.org/sqlite` parses and executes on each newly opened connection.
- **`New(":memory:")` compatibility:** In SQLite, executing `PRAGMA journal_mode=WAL` on an in-memory database is a harmless no-op (it returns `"memory"` without error), so in-memory databases continue to work.
- **No failing scenario:** Although `db.Exec` only executes against a single connection checked out from the pool and is therefore redundant, it does not produce an error or degrade connection settings because the DSN already guarantees pool-wide configuration.
